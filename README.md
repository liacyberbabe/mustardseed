# Mustard Seed LLC — Website

A monochromatic, editorial-style static website starter for Mustard Seed LLC, a premium wholesale blank apparel business.

## Files

- `index.html` — Home
- `shop.html` — Shop / product catalog
- `about.html` — About
- `policies.html` — Policies
- `terms.html` — Terms & Conditions
- `contact.html` — Contact form
- `styles.css` — Complete site styling
- `script.js` — Product data, filtering, navigation

## Deploy to GitHub Pages

1. Create a new GitHub repository.
2. Upload all files in this folder to the repository root.
3. Commit the files.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save. GitHub will provide your public Pages URL.

## Before launch

Replace:
- Placeholder product images with your actual black-and-white product photography.
- Placeholder product names/specifications/pricing with your real catalog.
- `hello@mustardseedblank.com` with your actual business email.
- The Formspree URL in `contact.html` with your actual form endpoint.
- The starter legal text with your final policies reviewed for your business.
- Any brand/domain information in the footer.

## E-commerce note

This version is intentionally a lightweight GitHub Pages-compatible front end. It does not process payments or manage inventory. For real wholesale checkout, connect the Shop to an e-commerce platform or backend (for example Shopify, WooCommerce, or another wholesale-capable system).
